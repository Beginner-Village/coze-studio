# @coze-arch/import-watch-loader

A architecture package for the Ynet Studio monorepo

## Overview

This package is part of the Ynet Studio monorepo and provides architecture functionality. It serves as a core component in the Coze ecosystem.

## Getting Started

### Installation

Add this package to your `package.json`:

```json
{
  "dependencies": {
    "@coze-arch/import-watch-loader": "workspace:*"
  }
}
```

Then run:

```bash
rush update
```
