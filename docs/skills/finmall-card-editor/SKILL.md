# finmall 卡片编辑器操作技能（渐进式）

finmallclaw 像人一样操作卡片编辑器：**拖组件 → 选节点 → 改属性/样式 → 绑事件**，画布实时渲染、用户全程可见。
本技能不走"AI 一键生成",也不直接 PUT schema,而是用界面操作逐步搭建。

> 后端：编辑器是 finmall 预编译 H5,数据走 `/aop-web/IDC*.do`(coze-studio 已反代,同源可用)。
> 读卡片 `IDC10012`;编辑器内存即时渲染。**保存/发布留到最后**(已发布卡片自动保存可能 `交易失败 PEO000003`,
> 与搭建过程无关;调试时可用浏览器把 `IDC10010.do` mock 成成功以免错误弹窗打断)。

---

## Level 0 — 打开编辑器到「设计态」
卡片需先存在并有 `cardId`(用户手动新建空卡片)。打开(**别带 `showType=view`**,否则只读)：
```
http://<host>/agent-h5/?app=simple#/m_cardEditor/editor/design?id=<cardId>
```
三栏布局：
- **左栏**：`模板 / 组件 / 结构`。`组件`=组件区(布局组件+基础组件);`结构`=节点树("卡片结构"),选中/嵌套/排序靠它。
- **中栏**：画布(**iframe**,宽 375,所见即所得)。
- **右栏**：`属性 / 事件`。选中节点后显示其属性与样式;`事件` tab 绑动作。

每步操作后**截图核对画布**再继续。

---

## Level 1 — 4 个核心原语
1. **拖组件 `drag(label → 画布坐标)`**：组件是带文字 label 的元素。画布是 iframe,用**坐标拖拽**：
   `mousemove 到组件中心 → mousedown → 分3~4步 mousemove 到投放点 → 末尾再微移一次 → mouseup`。
   (必须分步移动,单跳不触发 DnD。)落下后新组件出现并**自动选中**,右栏切到它的属性。
2. **选节点**：画布内**点击**;深层/重叠用左栏 **`结构` tab** 点节点树(更准),还能在树里拖动**改父子/排序**。
3. **改属性/样式**：右栏面板——输入框 `fill` 写值;选项点按钮;颜色点色块填 #hex。改完画布立即变。
4. **绑事件**：`事件` tab → 开事件开关 → 选动作类型 → 填参数(见 Level 5)。

---

## Level 2 — 通用属性（几乎所有组件都有 = "通用性")
选中任意组件,右栏底部这组属性基本都有：
- **背景**：透明 / 颜色 / 图片 / 渐变色(+背景颜色取色)
- **内边距 / 外边距**：无 / 全边 / 自定义(可分别设 上右下左)
- **圆角**：无 / 全角 / 自定义
- **宽度 / 高度**：数值 + 单位(px / % / @自适应)
- **边框 / 阴影 / 旋转(deg) / 溢出(隐藏/可见) / 不透明度(%)**
- **显隐设置**：始终显示 / 满足条件显示 / 满足条件隐藏
- **空间不足时压缩节点**：开关
- **事件**：见 Level 5(不同组件事件名不同)

记住通用项后,每个组件只需再记它的**特殊属性**。

## Level 3 — 各组件详解（"加了它就知道能干啥" = "特殊性")

### 基础组件
| 组件 | 用途 | 特殊属性(独有) | 事件 |
|---|---|---|---|
| **文本 Text** | 单行/多行文字 | 内容、常用样式(黑/灰/淡灰/热门/热销/理财/存款等预设)、字体颜色、字体大小、行高、对齐(左/中/右)、字体权重(常规/中等/加粗)、字体样式、字体修饰、最大行数 | 点击事件 |
| **多文本 MultiText** | 多段文字组合(富排版) | 文本列表(多段)、行高、对齐、水平对齐、垂直对齐 | 点击事件 |
| **按钮 Button** | 可点击按钮 | 按钮文字、禁用按钮、字体颜色/大小/权重 | **点击事件(核心)** |
| **图片 Image** | 图片 | 图片地址、裁剪模式(铺满缩放/填充缩放) | 点击事件 |
| **图标 Icon** | 图标 | 图标(选择)、图标颜色、自定义图标 | 点击事件 |
| **输入框 Input** | 文本输入 | 绑定变量、占位符、类型、最大长度、字体颜色/大小/对齐/权重 | (输入相关) |
| **滑块 Slider** | 数值滑动条 | **绑定变量、最小值、最大值、步长、背景色、前景色、滑块样式/颜色/宽/高** | **值改变事件** |
| **复选框 Checkbox** | 多选 | 绑定变量、选项列表、选中/未选中颜色、样式类型、选中数量限制、排列方向、选项间距、文字图标间距、字体大小、icon大小 | **选项发生改变** |
| **单选框 Radio** | 单选 | 绑定变量、选中/未选中颜色、样式类型、显示文字、文字内容、文字图标间距、字体/icon大小 | **选项发生改变** |
| **视频 Video** | 视频 | 视频地址、视频封面 | — |
| **地图 Map** | 地图 | 中心经纬度、缩放比、标记点经纬度/名称 | — |
| **分割线 Divider** | 分隔线 | (仅通用:宽/高/外边距) | — |
| **画布 Canvas** | 自由绘制容器 | (画布内自定义) | — |
| **自定义 Custom** | 自定义渲染(内测) | 自定义内容 | — |

### 布局组件（容器,用来嵌套子组件）
| 组件 | 用途 | 特殊属性 |
|---|---|---|
| **行布局 Row** | 横向排子节点 | 排列方向(横向/竖向)、**水平对齐、垂直对齐**、元素间距(gap) |
| **列布局 Column** | 纵向排子节点 | 排列方向、垂直对齐、水平对齐、元素间距 |
| **多列布局 MultiColumn** | 等分多列 | 元素间距(+按列放子节点) |
| **列表布局 ListLayout** | 数据驱动的重复列表 | **数据源**、方向(纵向/横向)、项内边距 |
| **网格布局 GridLayout** | 网格 | **数据源、列数目、行间距、列间距** |
| **绝对布局 AbsoluteLayout** | 子节点绝对定位 | 对齐方式 |

> 输入类(输入框/滑块/复选框/单选框)都有 **绑定变量** —— 绑到卡片「变量」(左上角 `变量` tab),
> 实现取值/回填,常配合事件把值送回智能体。

## Level 4 — 布局配方 / 嵌套技巧（关键细节,务必照此做）

画布默认按 Root(列方向)从上到下堆叠。要实现特定排布,**靠"容器 + 对齐"组合**,而不是硬调单个组件位置：

- **让按钮/元素水平居中** → 外面套一个 **行布局(Row)**,把元素拖进去,设 Row 的 `水平对齐 = 居中`。
  (或者让按钮 `宽度 = 100%` 做成满宽按钮。)
- **一行两端(左标签 + 右值/箭头)**,如"生效时间 ──→ 2025-08-22 >" → **行布局**,`水平对齐 = 两端对齐`,
  里面放 左`文本` + 右侧(`文本`+`图标`箭头)。
- **左右两块等分**(如滑块下"当前额度 | 最高可调额度") → **行布局** `水平对齐=两端对齐` 或 **多列布局**。
- **纵向带间距堆叠** → 用 列布局/Root 的 `元素间距(gap)` 统一控制,别给每个子组件加外边距。
- **垂直居中对齐一行内不同高度的元素** → Row 的 `垂直对齐 = 居中`。
- **重复的列表项**(N 条结构相同) → 列表布局 + 数据源,而不是手动拖 N 份。
- **卡片整体留白/底色/圆角** → 选中 `Root`(卡片本身)设 内边距/背景/圆角/元素间距。

**嵌套操作要点**：
1. 先拖**外层容器**,选中它,记下它在画布的包围盒。
2. 把子组件拖到**落在该容器包围盒内**的点(否则会落到 Root)。
3. 到 `结构` tab 确认父子层级对不对;错了就在结构树里把节点拖到正确父节点下,或撤销重来。
4. 自顶向下:先搭好骨架容器,再往里填叶子组件。

## Level 5 — 事件（绑定与"发消息给智能体"）
选中组件 → `事件` tab → 打开事件开关(文本/按钮等是「点击事件」;滑块是「值改变事件」;复/单选框是「选项发生改变」)
→ 选**动作类型**：

| 动作类型 | 含义 | 绑定参数 |
|---|---|---|
| 无 | 不绑 | — |
| 自定义处理 | 自定义/插槽逻辑 | 处理标识 |
| **发送智能体信息** | 点击后**向智能体(finmallclaw)发一条消息** —— 卡片↔Agent 核心通道 | 消息内容/参数(如把滑块选定额度回传) |
| 页面跳转 | 跳链接 / 跳另一张卡片 | URL / cardId |
| 关闭弹窗 | 关闭当前弹层 | — |

> 「发送智能体信息」让卡片能驱动对话:给「确定」按钮绑它,用户点完就把结果发回 finmallclaw,形成
> "卡片操作 → 回到对话"的闭环。finmallclaw 搭卡片时应主动给交互元素绑合适事件。

---

## Level 6 — schema 树（理解嵌套,不用于手写）
卡片是递归树,根 `Root`。**子节点在节点的 `components` 数组**里。节点字段：
`width / className / style{properties:[{itemKey,itemValue,...}]} / properties / eventactions / components`。
允许用 `IDC10012` 读参考卡的 schema 来**理解**结构(读≠生成 DSL),据此规划要在 UI 里搭的树。

## 完整实战：复刻「调整信用卡额度」卡片
目标树：
```
Root(列, gap=12, 白底, 圆角10, 内边距16)
├─ 文本「调整信用卡额度」(18px 加粗)
├─ 行布局: 文本「调整临时额度至 」+ 文本「¥80,000」(#FF6A00 加粗 20px)
├─ 滑块(min=30000,max=80000,当前=80000,前景色橙)
├─ 行布局(水平对齐=两端): 多文本「¥30,000 / 当前额度」 | 多文本「¥80,000 / 最高可调额度」
├─ 行布局(两端): 文本「生效时间」 | (文本「2025-08-22」+图标 右箭头)
├─ 分割线
├─ 行布局(两端): 文本「失效时间」 | (文本「2026-08-22」+图标 右箭头)
└─ 行布局(水平对齐=居中): 按钮「确定」(#2F6BFF 白字 满宽 圆角8) ← 居中靠外层 Row
```
逐步:每步拖组件→改特殊属性→(交互元素)绑事件→截图核对。按 Level 4 的配方控制对齐与嵌套。
保存/发布按用户指示最后处理。

## 实操踩坑（playwright 实测,务必照做）
- **新建卡片**：资源库 `创建卡片` → 填 卡片编码/名称/类型 → **卡片封面必填**(不传则提交被拦"请上传服务图标"),
  用 `setInputFiles` 给 `input[type=file]` 设图(上传走 `/aop-web/common/uploadFile`) → `提交并部署`。创建接口 `IDC10002.do`。
- **投放位置**：拖第 2+ 个组件时,投放点要落在**已有内容下方的空白区**;落在已有节点上只会"选中"它而不新增。
- **改内容后画布不刷新**：`fill` 只设了值不触发渲染;需**触发 input 事件再失焦**(在字段里敲一个字符+退格,再 Tab/点别处),画布才更新。
- **没有"清空画布"按钮**(页面里的"清空"是取色器的)。删节点:画布上右键→`删除元素`(自动化下右键菜单较脆,优先用「结构」树选中后操作)。
- **自动保存报错**:编辑时编辑器自动调 `IDC10010` 保存,可能弹"错误/交易失败"模态框(后端业务规则),点`确定`关掉即可,不影响画布;批量自动化时可用浏览器把 `IDC10010.do` mock 成 `{"header":{"errorCode":"0"}}` 免打断。
- 打开编辑器 URL 即使带 `showType=view` 也仍可拖拽编辑(实测)。

## 注意事项 / 易踩坑
- 打开务必去掉 `showType=view`。
- 画布是 iframe:跨 iframe 拖拽用**屏幕坐标**;选节点优先 `结构` tab。
- 拖拽必须**分步移动鼠标**。
- 居中/两端/等分等排布**靠容器+对齐**实现,不是调单个组件坐标。
- 嵌套后到 `结构` tab 校验层级;落错用结构树移动或撤销。
- 不同组件**事件名不同**(点击/值改变/选项改变)。
- `filestore` 图片偶发 403(线上双前缀数据 bug),不影响搭建。
- 保存:已发布卡片自动保存可能 `交易失败`,属后端业务规则,持久化策略另议。
